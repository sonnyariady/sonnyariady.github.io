AI-Assisted Data Transformation

Case Study: End-to-End Enterprise Data Migration using Antigravity AI

C# .NET 9.0 Antigravity AI PostgreSQL Microsoft SQL Server Excel Import VARBINARY File Extraction ETL Automation

Overview

This portfolio demonstrates an enterprise-grade data transformation workflow completed primarily through Antigravity AI. The project migrated heterogeneous data from Microsoft SQL Server and Microsoft Excel into PostgreSQL, including binary file extraction, AI-assisted business rule mapping, automated C# .NET 9.0 code generation, and validation of migrated records.

Project Highlights

Source & Destination

  • Source Systems: Microsoft SQL Server + Excel
  • Destination: PostgreSQL Database
  • Programming Language: C# (.NET 9.0)
  • AI Assistant: Antigravity IDE

Core Features

  • Binary Migration: SQL Server VARBINARY(MAX) → Physical Files
  • Dynamic File Naming: Generated from Reference ID
  • Rule-Based Mapping: Driven by natural-language AI prompts
  • Excel Integration: Drag-and-drop file import support

AI Workflow Steps

End-to-end 9-step execution lifecycle orchestrated with AI code generation:

Step Description
Step 1 Provide SQL Server & PostgreSQL connection strings.
Step 2 Drop Excel file into the application interface.
Step 3 Describe data transformation rules in natural language prompts.
Step 4 Antigravity AI generates C# .NET 9 ETL implementation code.
Step 5 Read and parse SQL Server tables & Excel sheet data.
Step 6 Apply automated business mapping rules to column definitions.
Step 7 Extract VARBINARY binary document files and save as <ReferenceID>.<extension>.
Step 8 Insert transformed relational records into target PostgreSQL database.
Step 9 Generate detailed migration execution and validation report log.

Example AI Prompt

Sample prompt used to direct Antigravity AI for generating the complete migration executable:

Generate a C# .NET 9.0 console application. Read data from SQL Server and Excel. Use the provided connection strings. Transform Status values according to the supplied mapping rules. Download VARBINARY files and save them using the corresponding ReferenceID. Insert the transformed records into PostgreSQL and produce a migration log.

Business Value & Authorship

Business Impact

The solution significantly reduced manual ETL effort, accelerated development through prompt engineering, improved consistency of business-rule implementation, and automated binary document migration with deterministic file naming based on business reference identifiers.
