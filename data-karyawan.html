🚀 Vibe Coding & AI-Assisted Learning Blueprint

Aplikasi ini merupakan hasil karya Vibe Coding dan pengembangan AI-assisted yang dibangun sebagai proyek pembelajaran awal full-stack CRUD (Python FastAPI + ReactJS).

💡 Proyek ini berfungsi sebagai pondasi awal dan cetak biru (learning blueprint) yang akan dikembangkan lebih lanjut untuk proyek-proyek aplikasi berikutnya dengan metode dan pendekatan terstruktur yang serupa.

Aplikasi Full-Stack Web modern untuk Manajemen Data Karyawan yang dilengkapi dengan Otentikasi JWT, CRUD lengkap, Lookup Supervisor dinamis, pencarian & filter multi-kriteria, serta fitur Ekspor Data ke format Excel (.xlsx) dan CSV (.csv).

✨ Fitur Utama

  • 🔒 Otentikasi & Keamanan JWT: Login berbasis JWT token dengan hash password aman (PBKDF2 SHA256).
  • 📋 Manajemen Data Karyawan (CRUD): Kode Karyawan (Unique Code), Nama Lengkap, Tanggal Lahir, Alamat, Nomor Telepon, Divisi, dan Supervisor / Atasan (Lookup Dropdown dinamis).
  • 🔍 Pencarian & Multi-Filtering: Instant Search (Kode, Nama, Telepon), Filter berdasarkan Divisi, Filter berdasarkan Supervisor, dan Reset Filter 1-Klik.
  • 📊 Ekspor Data Spreadsheet: Unduh data karyawan yang sedang difilter langsung ke file Excel (.xlsx) atau CSV (.csv).
  • 🎨 Modern Glassmorphism UI: Antarmuka responsif dengan tema Dark Slate, badge warna divisi, dialog modal interaktif, dan toast notification feedback.

🛠️ Teknologi yang Digunakan

Backend

  • Bahasa: Python 3.10+
  • Framework: FastAPI
  • Database: SQLite3 (SQLAlchemy ORM)
  • Otentikasi: PyJWT, hashlib PBKDF2
  • Data Export: pandas, openpyxl

Frontend

  • Framework: ReactJS (Vite)
  • Styling: Modern Vanilla CSS (Design Tokens & Glassmorphism)
  • HTTP Client: Axios (dengan Interceptor JWT Bearer Token)
  • Icons: Lucide React

🚀 Langkah-Langkah Menjalankan Proyek

# 1. Clone Repository
git clone https://github.com/sonnyariady/fastapi-react-employee-crud.git
cd DataKaryawan

# 2. Menjalankan Backend (Python FastAPI)
cd backend
python -m venv venv
.\venv\Scripts\Activate.ps1   # (Windows PowerShell)
pip install -r requirements.txt
python -m uvicorn main:app --reload --host 127.0.0.1 --port 8000

# Backend Server: http://127.0.0.1:8000
# Swagger API Docs: http://127.0.0.1:8000/docs

# 3. Menjalankan Frontend (ReactJS)
# (Di terminal baru)
cd frontend
npm install
npm run dev

# Frontend Server: http://127.0.0.1:5173

⚡ 3. Aturan Bisnis & Validasi (Business Rules)

# Bahasa Indonesia English
1 Keunikan Kode Karyawan: kode_karyawan tidak boleh duplikat (Case-insensitive unique check). Unique Employee Code: kode_karyawan must be unique (Case-insensitive unique check).
2 Validasi Self-Supervisor: Karyawan TIDAK BOLEH memilih dirinya sendiri sebagai supervisor_id (supervisor_id != id). Self-Supervisor Validation: Employee CANNOT select themselves as their supervisor_id (supervisor_id != id).
3 Pembersihan Referensi Bawahan: Jika supervisor A dihapus, seluruh bawahan A diubah nilai supervisor_id-nya menjadi NULL. Subordinate Cascade Reset: If supervisor A is deleted, all subordinates of A must have their supervisor_id reset to NULL.
4 Konsistensi Ekspor: File Excel / CSV WAJIB mengikuti kriteria filter pencarian user yang sedang aktif. Export Consistency: Generated Excel/CSV files MUST reflect active user search/filter criteria.

📖 SECTION 3: Panduan Pengguna & Operasi Sistem (USER MANUAL) 📖 SECTION 3: User Manual & Step-by-Step Operations

Petunjuk penggunaan lengkap dari aplikasi Sistem Manajemen Data Karyawan.

  1. Memulai & Login: Buka http://127.0.0.1:5173 di browser. Masukkan kredensial admin / admin123 (atau klik kotak demo login) lalu tekan Masuk ke Sistem.
  2. Dashboard Utama: Menampilkan Header, Toolbar Filter & Aksi, Tabel Data Karyawan (Nomor, Kode, Nama, Tanggal Lahir, Telepon, Divisi, Supervisor, Aksi), serta Pagination bar.
  3. Pencarian & Multi-Filtering: Masukkan nama/kode/telepon di kotak pencarian instan, filter berdasarkan Divisi, filter berdasarkan Supervisor, atau tekan tombol Reset Filter.
  4. Tambah Data Karyawan Baru: Klik tombol + Tambah Karyawan di toolbar, isi Kode (unik), Nama, Tanggal Lahir, Telepon, Divisi, Supervisor (opsional), Alamat, lalu tekan Simpan Data.
  5. Lihat Detail & Edit Data: Klik ikon Mata untuk membuka dialog modal profil detail karyawan, atau klik ikon Pensil untuk mengubah data karyawan.
  6. Hapus Data Karyawan: Klik ikon Hapus (Trash) pada baris karyawan. Jika karyawan tersebut merupakan supervisor bagi karyawan lain, relasi supervisor bawahan otomatis dilepas menjadi Top Level.
  7. Ekspor Data ke Excel & CSV: Klik tombol Export Excel atau Export CSV. File spreadsheet akan terunduh otomatis sesuai dengan data yang sedang aktif difilter.

Complete step-by-step user guide for operating the Employee Data Management System.

  1. Getting Started & Login: Open http://127.0.0.1:5173 in your browser. Enter credentials admin / admin123 (or click demo login box) then click Masuk ke Sistem.
  2. Main Dashboard: Displays Header, Filter & Action Toolbar, Employee Table (Index, Code, Name, Birth Date, Phone, Division, Supervisor, Actions), and Pagination bar.
  3. Search & Multi-Filtering: Type code/name/phone into search box, filter by Division dropdown, filter by Supervisor dropdown, or click Reset Filter.
  4. Add New Employee: Click + Tambah Karyawan button, fill Code (unique), Name, Birth Date, Phone, Division, Supervisor (optional), Address, then click Simpan Data.
  5. View Details & Edit Employee: Click Eye Icon to open profile detail modal, or click Pencil Icon to update employee details.
  6. Delete Employee: Click Trash Icon on employee row. If the deleted employee is a manager, subordinates' supervisor fields will automatically reset to Top Level.
  7. Data Export to Excel & CSV: Click Export Excel or Export CSV button. Spreadsheet file will download automatically matching active filters.
