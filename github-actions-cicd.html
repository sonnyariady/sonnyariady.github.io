CI/CD Portfolio - GitHub Actions

Automated Deployment for .NET 9 Applications on Private Ubuntu Development Infrastructure

GitHub Actions .NET 9.0 Docker Compose Linux Ubuntu SSH Authentication DevOps Automation

Overview

This portfolio summarizes the implementation of an automated CI/CD pipeline using GitHub Actions for a .NET 9 application. The deployment target is a Linux Ubuntu development server hosted on the organization's internal cloud infrastructure (non-AWS/Azure), accessible through a public IP over SSH.

Deployment Architecture

Automated pipeline flow from developer commit to live Docker container execution:

Developer → Pull Request → Merge → GitHub Actions → SSH Auth → Ubuntu Server → Execute deploy.sh → Application Updated

Key Responsibilities Matrix

Component Description
Platform GitHub Actions Workflow Engine
Language & Stack .NET 9.0 Console / Web Application
Infrastructure Private Ubuntu Linux Development Server (Internal Cloud Infrastructure)
Authentication SSH Public/Private Key pair authentication
Deployment Trigger Automatic release execution after every approved pull request merge
Container Runtime Docker & Docker Compose
Deployment Script Automated deploy.sh execution script
AI Assistance Standard GitHub Actions YAML workflow generated with AI and customized for target environment

GitHub Repository Secrets

The deployment workflow stores sensitive credentials securely using GitHub Actions Repository Secrets without exposing credentials in source control:

Configured Secrets

DEPLOY_HOST DEPLOY_PORT DEPLOY_USER DEPLOY_SSH_KEY SUDO_PASSWORD

Security Governance

All SSH credentials, IP addresses, ports, and sudo passphrases are injected into the runner dynamically at runtime, guaranteeing zero credential leaks in git history.

Deployment Flow Steps

1

Push & PR

Developer pushes code changes and creates a Pull Request.

2

Code Review & Merge

Changes are reviewed and merged into the target deployment branch.

3

Trigger Pipeline

GitHub Actions workflow is triggered automatically upon branch update.

4

SSH Authentication

Workflow authenticates securely to the Ubuntu server using configured SSH keys.

5

Execute Script

The workflow executes the remote deploy.sh deployment script on the Ubuntu server.

6

Docker Compose

Script executes Docker Compose rebuilds, prunes unused resources, and restarts updated containers.

7

Completion

Deployment finishes cleanly without requiring manual SSH terminal logins or manual Docker commands.

Business Value & Authorship

Business Impact

The implementation eliminated repetitive manual deployment activities, improved deployment consistency, reduced human error, and enabled faster delivery after every approved merge. Existing Docker Compose scripts created by another team member were reused, while GitHub Actions orchestrated the deployment lifecycle automatically.
